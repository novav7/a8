Aim: To create and use a HashMap in Java to store key-value pairs. Concept: HashMap is a class in the Java Collections Framework that stores data in key-value pairs. Each key is unique and is associated with a value. If the same key is added again, the old value is replaced with the new value. Features of HashMap: Stores data as key-value pairs. Keys are unique. Values can be duplicated. Does not maintain insertion order.
