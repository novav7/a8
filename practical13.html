Practical 3 : Array Creation and Slicing

• Create a NumPy array with 10 elements.



• Slice elements from 1st to 5th position.



• Demonstrate indexing techniques.

Aim

To demonstrate different indexing techniques in Python using strings, lists, and tuples.

1. Positive Indexing

Python uses zero-based indexing, so the first element has index 0.



2. Negative Indexing

Negative indexes access elements from the end of a sequence.



3. Indexing in Strings

Characters in a string can also be accessed using indexes.



4. Indexing in Tuples

Tuples support indexing in the same way as lists.



5. Indexing with Slicing

Slicing is used to access a range of elements.



6. Indexing with Step

A third value can be used to specify the step.



If you mean Python/NumPy, element-wise operations mean performing an operation on each corresponding element of an array.
