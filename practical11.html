Practical 1 : Introduction to NumPy Arrays

NumPy (Numerical Python) is a Python library used for working with arrays and performing mathematical operations efficiently.

Main Uses of NumPy Arrays

1. Store numerical data (integers, floats, etc.).

2. Perform mathematical operations such as addition, subtraction, multiplication, and division.

3. Matrix operations like matrix addition, multiplication, and transpose.

4. Statistical calculations such as mean, median, standard deviation, maximum, and minimum.

5. Data analysis and machine learning applications.

6. Scientific and engineering calculations.

7. Easy indexing and slicing of data.

8. Multi-dimensional arrays (1D, 2D, 3D, etc.).
